# Soal UAS

1. Silahkan Download Dataset
2. Import dataset kedalam program python sesuai dengan nomor kelompok
3. Silakan melakukan Exploratori Data Analysis (EDA) pada datasheet yang sudah ada
4. berikan kesimpulan mengenai dataset yang didapatkan
5. Silahkan Terapkan AI Supervised Learning pada dataset, sesuaikan algoritma dengan dataset yang didapat, dengan cara melakukan :
--- Sesuaikan rentang data / jumlah data dengan yang kalian perlukan
--- Lakukan "feature extraction" dan/atau "Tuning Hyperparameter" hingga mendapatkan hasil evaluasi yang paling bagus
--- Silahkan gunakan 2 Algoritma AI
--- Gunakan model evaluasi yang sesuai minimal 3 model evaluasi
6. Berikan kesimpulan pada hasil klasifikasi, bandingkan 2 hasil algoritma AI tersebut
7. Kumpulkan file project ke dalam 1 folder dengan nama folder UAS_Kelas_kelompokN yang berisikan:
--- 1 file PPT mengenai apa yang akan dipresentasikan
--- 1 file Word dengan format (Cover, Pendahuluan [penjelasan mengenai dataset], EDA, Tahap Persiapan, Tahap Preprocessing, Tahap Model Training, Tahap Evaluasi, Kesimpulan dan analisis hasil Machine Learning)
--- 1 file .py / .ipynb
8. Kemudian, folder tersebut harus dikompres menjadi file ZIP dengan nama UAS_Kelas_kelompokN dan unggahlah ke LMS oleh salah satu anggota kelompok maksimal hari Kamis, 18 Juni 2026, jam 23.59.
9. Keterlambatan dalam mengumpulkan proyek akan berakibat pada potongan nilai 20%
10. Ketidaksesuaian file dan folder yang dikumpulkan akan berakibat nilai tidak maksimal.

NB :
1) Pada PPT berikan Jobdesk masing2 anggota kelompok
2) Semakin dalam analisis yang kalian lakukan nilai akan semakin bagus
3) Semakin detail presentasi yang dilakukan nilai akan semakin bagus
4) Tuning Hyperparameter yang dilakukan sangat berpengaruh pada nilai
5) Hasil analisis sangat berpengaruh pada nilai
6) Penggunaan AI pada Level 3 hanya digunakan untuk penyelesaian error dan harus dilampirkan sebelum dan sesudah , Jika ketahuan melanggar nilai UTS akan mendapatkan  0
